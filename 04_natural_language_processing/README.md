# Natural Language Processing (NLP)

## 📌 Objective

This module introduces the fundamentals of **Natural Language Processing (NLP)**, focusing on how computers understand, process, and analyze human language. It covers text preprocessing, feature extraction, word representations, sequence models, and practical NLP applications using Python and TensorFlow.

---

## 📚 Topics Covered

### Text Processing

- Text Preprocessing
- Tokenization
- Stop Word Removal
- Stemming
- Lemmatization

### Feature Extraction

- Bag of Words (BoW)
- TF-IDF

### Word Representations

- Word Embeddings
- Word2Vec
- GloVe
- FastText

### Sequence Models

- RNN
- LSTM
- GRU

### NLP Applications

- Text Classification
- Sentiment Analysis
- Spam Detection
- Language Modeling

---

## 🎯 Learning Outcomes

After completing this module, you will be able to:

- Clean and preprocess text data.
- Convert text into numerical representations.
- Understand traditional NLP feature extraction methods.
- Learn dense word embeddings.
- Build sequence models for text data.
- Develop basic NLP applications using deep learning.
